    Found a bug?

    Bugs are tracked project by project, right where the code lives. Find the one you’re using on GitHub or Modrinth and open an issue there, not here — I read every single one.

    Browse projects on GitHub Browse projects on Modrinth

    What to include

    • Which Minecraft version you’re on
    • Which loader (Fabric, Forge, NeoForge, or Quilt) and its version
    • Steps to reproduce it
    • A crash report or log, if you’ve got one

    The more of this you include, the faster I can actually fix it.
