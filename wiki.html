    Which loader do I need?

    Every mod ships for Fabric, Forge, NeoForge, and Quilt, across every Minecraft version that supports it. Fabric is home base, so a new build usually lands there first, but the other three are never an afterthought. Use whichever loader you already run — you shouldn’t have to switch for one mod.

    Installing a mod

    1. 1

      Download the file that matches your Minecraft version and loader from Modrinth.

    2. 2

      Drop it into your mods folder.

    3. 3

      Launch with that loader’s profile. That’s it.
